# 模块级用户流程总览（MVP定稿）

> 适用版本：当前 MVP 决策稿  
> 关联文档：`AI穿搭助手_手机端界面设计指令.md`

---

## 1. 全局导航骨架

- 底部 Tab：`首页` / `衣橱` / `工坊` / `我的`
- 四个 Tab 根页无返回按钮
- 从根页进入子页后，Header 显示返回，返回到来源页
- `我的穿搭` 常驻入口在 `我的` 页（方案 B）
- 首页仅主推 `试穿新衣`

---

## 2. 冷启动流程（首次使用）

1. 打开 App
2. 进入引导页（3-5 页，可跳过）
3. 引导结束默认进入 `Screen/Home`（已定稿）
4. 若未设置模特：首页顶部显示 `点击设置您的模特`
5. 用户可点击提示条进入 `Screen/Model/Setup` 完成设置，或先直接试穿后补设模特

---

## 3. 模特模块流程

## 3.1 首次设置模特

- 入口：首页提示条 `点击设置您的模特` / 我的页 `我的模特`
- 流程：
  1. 进入 `模特设置页`
  2. 选择 `从相册选择` 或 `立即拍照`
  3. 预览后点击 `确认使用`
  4. 返回业务页（通常为首页）

## 3.2 更换模特

1. 我的 → `我的模特` → `更换模特`
2. 选择新图并确认
3. Toast：`模特已更新`
4. 弹窗：`是否重新生成所有衣物的上身效果图？`（`是` / `暂不`）
5. 选择 `是`：执行批量重算并显示进度
6. 若部分失败：Toast `部分衣物更新失败，可稍后重试`（MVP 不做失败列表页）

---

## 4. 试穿主流程（首页核心）

## 4.1 标准链路

1. 首页点击 `试穿新衣`
2. 进入选图并处理相册权限
3. 选中服装图后进入处理（必要时先去背景，再调用 AI 试穿）
4. 按时长显示加载文案
5. 成功后进入结果页（全屏图 + 手势查看）

## 4.2 结果页三个去向

- `保存到衣橱`：保存成功 Toast `已保存到衣橱`
- `搭配衣橱其他衣服`：跳转工坊并默认选中当前试穿衣物
- `再试一件`：返回选图页继续试穿

## 4.3 异常分支

- AI 失败：进入错误页（`重新上传` / `返回首页`）
- 权限拒绝：提示并可 `前往设置`
- 异常退出恢复（MVP 最小策略）：
  - 仅恢复试穿链路（处理中/生成中/结果未离开）
  - 启动提示：`检测到上次未完成试穿，是否继续？`（`继续` / `取消`）
  - `继续`：回到对应状态页；`取消`：清理临时状态并进入首页

---

## 5. 衣橱模块流程

## 5.1 浏览与筛选

1. 进入 `衣橱` Tab
2. 网格浏览（录入时间倒序）
3. 品类筛选（全部/上衣/下装/连衣裙/外套/鞋子/配饰/其他）
4. 空状态可引导 `去试穿`
5. 支持下拉刷新和分页加载

## 5.2 详情与编辑

1. 点击衣物进入详情（原图/上身图切换）
2. 点击 `编辑` 修改名称、品类、颜色
3. 保存后 Toast `保存成功`
4. 点击 `删除` 需二次确认
5. 删除后返回列表并 Toast `已删除`

> 说明：回收站能力已明确为 Phase 2，不纳入 MVP 首发。

---

## 6. 工坊模块流程

## 6.1 进入工坊

- 入口 1：底部 Tab `工坊`
- 入口 2：试穿结果页 `搭配衣橱其他衣服`

## 6.2 搭配操作

1. 左侧模特区，右侧衣物列表
2. 点击衣物即时预览（本地缓存）
3. 组合规则：
   - 上衣 + 下装可合成
   - 选连衣裙清除上/下装
   - 外套可叠加
   - 超过 3 件提示复杂度建议

## 6.3 保存与分享

- 保存搭配：
  - 未选衣物给出提示
  - 成功后 Toast `搭配已保存`，并给 `查看我的穿搭` 快捷入口
- 分享：
  - 调系统分享面板
  - 或保存到相册（需相册写权限）

---

## 7. 我的穿搭模块流程（方案 B）

## 7.1 入口策略

- 常驻入口：`我的` 页列表项 `我的穿搭`
- 临时入口：工坊保存成功后的 `查看我的穿搭`

## 7.2 列表与详情

1. 进入 `我的穿搭` 列表（时间倒序）
2. 点击记录进入详情（搭配图 + 衣物列表）
3. 可 `再次编辑` 回工坊并自动加载该搭配
4. 长按记录可 `编辑` / `删除` / `分享`
5. 若衣物缺失，提示原搭配中有被删除项

## 7.3 返回栈

- 从 `我的` 进入：返回 `我的`
- 从工坊快捷入口进入：返回 `工坊`

---

## 8. 我的页流程（个人中心）

当前顺序（已定）：

1. `我的模特`
2. `我的穿搭`
3. `查看新手教程`

说明：

- `我的穿搭` 必须在 `查看新手教程` 之前
- `查看新手教程` 作为 NFR-5 的复学入口保留

---

## 9. 首次引导气泡策略（MVP）

- 覆盖范围（最小版 3 处）：
  1. 首页试穿入口
  2. 衣橱空状态
  3. 工坊空状态
- 频次：每个气泡仅出现 1 次

---

## 10. MVP 与 Phase 2 边界

## MVP 已纳入

- Tab A 导航
- 首页仅主推试穿
- 我的穿搭方案 B
- 模特更换批量失败仅 Toast
- 异常退出最小恢复（仅试穿链路）
- 首次引导气泡最小版 3 处

## Phase 2（暂不纳入 MVP）

- 回收站（24 小时恢复）
- 批量失败项列表与逐条重试页
- 扩展型引导气泡（结果页手势等）
