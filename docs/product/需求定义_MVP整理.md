# 需求定义整理（MVP）

> 依据：`衣橱EARS需求文档.md`、`模块级用户流程总览_MVP定稿.md`。  
> **优先级说明**：**P0** = MVP 必须有；**P1** = MVP 重要体验/规则细化；**延后** = 定稿明确首期不交付或 Phase 2。

---

## 一、产品目标及定位

### 1. 产品定位

- **一句话**：面向 **18–35 岁女性** 的移动端 **AI 穿搭助手**，以 **虚拟试穿** 为价值入口，以 **本地衣橱 + 穿搭工坊 + 我的穿搭** 承接留存与复逛。  
- **价值主张**：缓解 **「网购看不见上身效果」** 与 **「衣橱闲置」** ——先让用户 **快试、敢存、能搭**。  
- **形态边界**：**首页仅主推试穿**；底部 **四 Tab——首页 / 衣橱 / 穿搭（工坊）/ 我的**；`我的穿搭` 入口按 **方案 B** 放在 **我的** 页。

### 2. 产品目标（与需求文档成功标准对齐，作 MVP 方向）

| 维度 | 目标（方向） |
|------|----------------|
| **核心体验** | 试穿链路可用、结果可保存、可跳转搭配；衣橱可管、工坊可合成并沉淀穿搭记录。 |
| **性能** | 期望 **约 3 秒内** 给出上身效果（超时与等待文案按 NFR 分级提示）。 |
| **增长/活跃** | 提升 **试穿成功率、次日留存、衣橱活跃、搭配创建率**（具体数值见需求文档成功标准表，上线后按数据复盘）。 |
| **信任与合规** | 模特与效果图 **以本地为主**，网络用于 **AI API 调用**，隐私说明清晰（NFR-3）。 |

### 3. MVP 与延后边界（摘自定稿）

**MVP 已纳入**：四 Tab 导航；首页主推试穿；我的穿搭方案 B；模特更换批量失败仅 Toast（但 **更换模特流程本身首期不开发**）；试穿异常退出最小恢复；首次引导气泡最少 3 处（首页试穿、衣橱空、工坊空）。

**Phase 2 / 延后**：回收站（24h 恢复）；批量失败列表与逐条重试页；扩展型引导气泡；**模特更换（需求 2）**；**搭配分享（需求 18）**。

## 二、需求列表

### MVP 核心需求清单（PM 精简版 · 11 条）

**用途**：评审/汇报/一页纸；**粒度**为业务能力，非单接口验收。拆分与验收请以本章后文 **`F-xx` 分解表** 为准。  
**编号**：`MVP-P##` — **P** 表示 Principal（核心条目），均为 **P0**。

| 编号      | 需求名称        | 优先级 | 描述（What & So what）                               |
| ------- | ----------- | --- | ------------------------------------------------ |
| MVP-P01 | 应用信息架构四 Tab | P0  | 定义「试穿—衣橱—工坊—个人」主轴；首页只拉试穿心智；深层页一键回到来源上下文。         |
| MVP-P02 | 首启与轻量教育     | P0  | 首轮功能介绍可跳过；三处触点各出现一次提示，不穿墙、不搞运营骚扰。                |
| MVP-P03 | 数字模特首设      | P0  | 相册/相机建立模特；不达标即挡住；可先逛后补，弱提示收口到「补上模特」。             |
| MVP-P04 | AI 试穿主路径    | P0  | 选衣图→授权→远端生成上身图→等待与异常有交代；体感向「几秒级」看齐。              |
| MVP-P05 | 试穿页结果收口     | P0  | 全屏可看上身效果；三件续跑：落成衣橱卡片、跳进工坊沿用当前单品、或直接再试一件。         |
| MVP-P06 | 本地衣橱可看可找    | P0  | 衣橱时间线/网格、下拉与分页；按品类收窄；衣物卡下钻比对原衣与上身。               |
| MVP-P07 | 衣物资产可删可改    | P0  | 元数据改名类色随手改； deletion 二次确认，防手滑，删完给明确反馈。           |
| MVP-P08 | 工坊搭配画布      | P0  | 左侧人右侧衣；多件按规则预览合成；过复杂给提示而非静默崩感；存成套装。              |
| MVP-P09 | 穿搭记录可追溯     | P0  | 「我的穿搭」回看历史套装；物料缺失要说话；一键回工坊改套不改叙述成本。              |
| MVP-P10 | 个人聚合与复学     | P0  | 「我的」里模特档案、穿搭库、说明书顺序固定；老用户能快速找回学习中心。              |
| MVP-P11 | 可用性与信任底线    | P0  | 试穿半道闪退要能续或弃；口径：肖像与上身产出以终端为主存，云上只服务必要推断，权限文案要说人话。 |

**首期明确不做（别写进上面 11 条）**：整机换模特主流程（定稿延后）、成片级分享链路、回收站与批量失败逐条工单类能力。

### 功能性需求

| 编号 | 需求名称 | 优先级 | 模块 | 简述（描述） |
|------|----------|--------|------|----------------|
| F-01 | 模特上传与初始化 | P0 | 模特 | 引导/相册拍照、预览与确认、校验不合格重选；跳过则用占位模特 + **首页顶栏**「点击设置您的模特」。 |
| F-02 | 模特更换 | 延后 | 模特 | **首期不开发**（定稿）；需求文档留存换模、批量重生与失败 Toast 叙事供后续迭代。 |
| F-03 | 衣物图片选择 | P0 | 试穿 | 首页「试穿新衣」→ 系统相册；处理 **相册权限**，拒绝时可 **前往设置**。 |
| F-04 | AI 试穿处理 | P0 | 试穿 | 选图后进加载流程，调 **AI 试穿接口**生成上身图；失败/超时/慢网提示。**注**：需求文档写「先去背景再生图」——**若以当前产品为准无独立去背步骤，则实施为直连试穿服务，本条以实现对齐**。 |
| F-05 | 试穿结果展示 | P0 | 试穿 | 全屏效果图；缩放手势/旋转/平移/双击复位；底部 **保存衣橱 / 搭配其他 / 再试一件**。 |
| F-06 | 衣物保存到衣橱 | P0 | 衣橱 | 存原图、上身图、录入时间、默认品类等本地数据；保存成功 Toast。 |
| F-07 | 跳转穿搭工坊 | P0 | 工坊 | 从结果页进工坊并 **默认选中当前试穿衣物**；衣橱空则引导试穿。 |
| F-08 | 继续试穿 | P0 | 试穿 | 「再试一件」回选图，连续试穿；超量提示按需（需求文档 5 件规则可作 P1）。 |
| F-09 | 衣橱网格浏览 | P0 | 衣橱 | 网格列表、录入时间倒序、下拉刷新、**分页**、空态「去试穿」。 |
| F-10 | 衣物详情 | P0 | 衣橱 | 原图与上身图 **滑切查看**；提供编辑、删除入口。 |
| F-11 | 衣物信息编辑 | P0 | 衣橱 | 编辑名称、品类、颜色；品类枚举与定稿一致；保存 Toast。 |
| F-12 | 衣物删除 | P0 | 衣橱 | **MVP 定稿已要做**：二次确认、删除后回列表 Toast。（需求文档曾在另一处写「第一版不开发」——**以实现定稿为准**。） |
| F-13 | 衣橱品类筛选 | P0 | 衣橱 | 全部/上衣/下装等筛选与数量反馈、空筛选提示。 |
| F-14 | 工坊基础布局 | P0 | 工坊 | 左模特区右列表；未设模特占位进设置；衣橱空引导试穿。 |
| F-15 | 单件搭配预览 | P0 | 工坊 | 点击缩略图 **本地缓存**预览，选中态与切换规则。 |
| F-16 | 多件组合与合成规则 | P0 | 工坊 | 上装+下装合成；连衣裙清空上下装；外套叠穿；超过 3 件复杂度提示。 |
| F-17 | 保存搭配方案 | P0 | 我的穿搭 | 存搭配图、衣物 ID、时间等；成功 Toast + **查看我的穿搭** 入口。 |
| F-18 | 搭配分享 | 延后 | 我的穿搭 | **首期不开发**（定稿）；含系统分享/存相册权限（需求留存）。 |
| F-19 | 我的穿搭列表 | P0 | 我的穿搭 | 时间倒序、下拉刷新、空态引导；长按 **编辑/删除/分享**——**分享能力首期不做时，可降级为只做编辑/删除或隐藏分享**。 |
| F-20 | 穿搭详情与再编辑 | P0 | 我的穿搭 | 详情展示列表；**再次编辑**回工坊并载入；衣物已删提示缺件；返回栈遵循定稿。 |

### 非功能性需求（摘要列表）

| 编号 | 需求名称 | 优先级 | 说明 |
|------|----------|--------|------|
| NFR-01 | 性能 | P0 | 试穿首屏耗时目标、衣橱首屏约 1s、缩略图渐进加载等。 |
| NFR-02 | 容错 | P0 | API 失败、弱网、**试穿链路异常退出后可选择继续/取消**（定稿最小策略）。 |
| NFR-03 | 隐私 | P0 | 模特与效果图本地化主张；删除彻底；权限用途说明。 |
| NFR-04 | 兼容 | P1 | 常见屏宽、双端一致性、存储与低端机降级。 |
| NFR-05 | 易用引导 | P0 | 首次 **3–5 页引导可跳过**；**气泡三处单次**；**我的**内「查看新手教程」复学。 |

### 边缘与数据（节选纳入范围）

| 编号 | 需求名称 | 优先级 | 说明 |
|------|----------|--------|------|
| EC-01 | 图片格式/大小 | P1 | 不支持格式与过大文件的提示策略。 |
| EC-02 | 模特照片质量 | P0 | 与 F-01 校验一致：全身、单人、清晰度等提示。 |
| EC-03 | 衣橱数据损坏/回收站 | 混合 | MVP **无回收站**；「数据损坏修复」若在实现范围则 P1/P2，**勿与 Phase2 回收站混为一谈**。 |

## 三、与原文档差异备忘（评审用）

1. **删除衣物**：以实现 **模块级 MVP 定稿（§5.2）** 为准，**首期提供**。  
2. **模特更换**：EARS 需求仍存在，定稿明确 **首期不开发**。  
3. **分享**：工坊/穿搭记录的分享 **首期不开发**；交互上可避免露出或置灰并配文案「敬请期待」。  
4. **去背**：若在工程上不做独立步骤，须在 PRD/Issue **显式废止或标 Phase**，避免测试按旧 EARS「先去背」验收。
