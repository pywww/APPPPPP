## 设计稿完成后交付给开发的无代码操作指南（H5 链接版）

本指南面向**没有代码基础**的你，目标是把你修改好的 Figma 设计稿交付给我/开发团队，最终让你能在手机上通过**链接版 H5**体验你的 APP Demo。

---

### 一、交付你需要准备的“三件套”

1. **① Figma 可访问链接（按页面/画板）**
   - 对每个需要开发的界面（例如 `Screen/Home`、`Screen/Wardrobe`…）复制一个带 `node-id` 的链接。
2. **② 需求文档**
   - 你已有：`模块级用户流程总览_MVP定稿.md`、`衣橱EARS需求文档.md`
   - 会作为开发对齐依据（特别是异常态、交互流程、MVP 边界）。
3. **③ 切图资源（可选）**
   - 不是一开始就必须。图标/插图导出可在需要时补齐。

> 注意：**不要**指望在 Figma 里“导出代码”作为正式交付。导出的通常是片段化代码/参考样式，维护成本高。

---

### 二、你电脑上建议先建的文件夹

在桌面或任意位置新建一个项目资料夹，例如：

- `衣橱App-交付资料`

并在里面建三个子文件夹：

- `01-需求文档`
- `02-Figma链接`
- `03-切图资源`（可空着）

把你现有需求文档放进 `01-需求文档`，把 Figma 链接表放进 `02-Figma链接`。

---

### 三、Figma 里如何复制“正确的链接”（重点）

对每个需要开发的界面，重复以下操作：

1. 打开你的 Figma 文件，左侧图层列表中**单击选中该界面的最外层画板/Frame**  
   - 通常名字类似 `Screen/Home`、`Screen/Wardrobe/Detail`
   - 不要只选中画板内部某个按钮/文本层
2. 在选中该 Frame 后，右键该 Frame → 选择 **Copy link / 复制链接**
3. 粘贴链接到记事本/表格
4. 检查链接里是否包含 `node-id=`  
   - 有 `node-id`：基本正确  
   - 没有 `node-id`：说明你可能复制错层级；重新选中最外层 `Screen/...` 再复制

建议你粘贴链接时附一行备注，便于开发快速确认：

```text
首页（试穿入口）	<你的带node-id链接>
衣橱列表	<你的带node-id链接>
...
```

---

### 四、整理成“交付表”（强烈建议用表格）

你可以用 Excel/ WPS 表格/腾讯文档，或直接用 Markdown 表格。推荐列：

- `序号`
- `界面名称（中文）`
- `Figma Screen 名`
- `Figma 链接（带 node-id）`
- `是否第一版要做（是/否）`

至少先把 MVP 第一版要做的界面填上，后续再补 Phase 2。

---

### 五、共享权限：确保链接打开能看到内容

在 Figma 里：

1. 右上角点 `Share`
2. 设置为：
   - `Anyone with the link`（知道链接的人可查看），或邀请开发者邮箱
3. 权限至少要有 **View（查看）**

否则开发可能会拿不到你要对齐的结构信息。

---

### 六、在 Cursor 里交给我/开发的操作流程

你只需要会“打开文件夹 + 发消息”，不需要写代码：

1. 打开 Cursor
2. `File` → `Open Folder`（打开文件夹）
   - 打开你的项目文件夹（或新建一个如：`衣橱App-前端H5` 的空目录）
3. 在对话里把以下内容发给我：
   - 你用的技术栈（如果你还没定，我会建议）
   - 交付表/链接表（直接粘贴）
   - 说明需求文档放在哪个文件夹（例如你放在项目根目录的某个路径）

你可以用这个模板发我（直接替换占位符）：

```text
目标：只做链接版 H5 Demo。
需求文档：已放在 /01-需求文档。
Figma链接表：见下方（粘贴整表）。
第一版范围：先做 Tab 壳 + 试穿闭环（选图/加载/结果/错误）+ 衣橱空态与保存到本地。
```

### 七、你需要自检的 7 件事（交付前必做）

- [x] 每个关键界面都有单独的带 `node-id` 的 Figma 链接
- [x] 链接里没有重复/重名导致开发对错画板（例如 `Empty` 不要只有一个同名）
- [x] 共享权限已开启，链接能被打开
- [x] 需求文档放在你说的路径中（或至少在你的资料夹里明确位置）
- [x] 交付表里标注了“第一版要做/第二版再做”
- [ ] 你确认要做的是“链接版 H5”（不是原生安装包）
- [ ] 你提前说明：AI 试穿调用是 Mock 先跑通还是必须接真实 API

---

### 八、如果你还不确定要导出什么（可选）

你可以先不导出任何资源，只交链接 + 需求文档。等前端按 UI 做到需要图片/图标时，再补 `03-切图资源` 即可。

需要导出时通常是：

- 图标（SVG 优先）
- 关键插图（PNG）
- 若你们约定了字体/配色 token，再补 token 表（截图或变量表均可）

---

## 你下一步只要做一件事

把你已修改完成的设计稿里，**第一版范围**对应的 `Screen/...` 全部复制链接并填入“交付表”，然后把这张表发到 Cursor 对话里即可。
